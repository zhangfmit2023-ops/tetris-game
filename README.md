# TETRIS · 1985

无第三方依赖的经典俄罗斯方块，全部代码位于 `index.html`。

## 开始玩

直接用现代浏览器打开 `index.html`，点击「开始游戏」即可。无需安装或构建。

也可以在仓库目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 操作

- ← / →：移动
- ↑：顺时针旋转
- ↓：加速下降，每格 1 分
- 空格：直接落地，每格 2 分
- P / Esc：暂停或继续；切换到其他标签页时自动暂停
- 点击「重新开始」开启新一局
- 手机可使用底部触屏按钮

10 × 20 棋盘、七袋随机的七种方块、下一个方块预览和落点轮廓。每消除 10 行升级，下降速度随等级增加。一次消除 1/2/3/4 行分别获得 100/300/500/800 × 当前等级分。包含像素方块、消行闪光和碎片效果。

## 豪华版

- 开局 3、2、1 倒计时，倒计时期间不会接收方块操作。
- 开局前选择轻松 / 经典 / 挑战难度（初始下降间隔 1100 / 800 / 480 毫秒），各难度仍随等级加速，原有计分规则不变。
- Web Audio 实时合成复古操作音效和循环背景音乐，无需下载音频；点击开始后启用，可分别关闭。暂停、结束或切出页面时停止音乐。
- 最高分自动保存在当前浏览器的 localStorage，刷新后保留。不同设备、浏览器或站点不共享；浏览器禁用存储时仍能玩，但记录无法跨刷新保留。
- 手机控制支持左右移动、下降长按连发，旋转和落地单次触发；按钮至少 56px 高，适配窄屏与底部安全区，支持多点触控。松手、暂停、重新开始和窗口失焦会清除长按状态。
