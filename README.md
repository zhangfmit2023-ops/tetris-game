# TETRIS · 1985

无第三方依赖的经典俄罗斯方块，全部代码位于 `index.html`。

## 开始玩

直接用现代浏览器打开 `index.html`，点击「开始游戏」即可。无需安装或构建。

也可以在仓库目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 操作

- ← / →：移动
- ↑：顺时针旋转
- ↓：加速下降，每格 1 分
- 空格：直接落地，每格 2 分
- P / Esc：暂停或继续；切换到其他标签页时自动暂停
- 点击「重新开始」开启新一局
- 手机可使用底部触屏按钮
